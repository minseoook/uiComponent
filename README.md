# 자주 쓰이는 UI 만들기 (2주/개인 프로젝트)

**기간:** 2024.10 ~ 현재  
**링크:** [프로젝트 보기](https://ui-component-minseok.vercel.app/)

## 소개

이 프로젝트는 실무에서 자주 사용되는 UI 컴포넌트를 라이브러리 없이 직접 개발해본 것입니다. 다양한 UI 요소를 구현하여 사용성과 재사용성을 고려한 컴포넌트를 만드는 데 초점을 맞췄습니다.


## 개발한 UI 컴포넌트

### 아코디언
- 접었다 펼 수 있는 아코디언 스타일의 컴포넌트입니다. 내용을 간결하게 정리하고 필요 시 확장할 수 있습니다.

### 레이지 로딩
- 페이지 로딩 속도를 개선하기 위해 이미지나 콘텐츠를 필요할 때만 로드하는 기능입니다.

### 모달
- 페이지 위에 떠 있는 대화상자 형태의 UI 요소로, 사용자의 주의를 끌거나 추가 정보를 표시할 때 사용합니다.

### 무한 스크롤
- 사용자가 페이지 하단에 도달하면 추가 콘텐츠를 자동으로 로드하는 기능입니다.

### 자동완성
- 사용자가 입력을 시작하면 가능한 옵션을 제안하는 기능으로, 입력 속도와 정확성을 높입니다.

### 캐러셀
- 여러 이미지나 콘텐츠를 슬라이드쇼 형태로 보여주는 컴포넌트입니다.

### 탭 메뉴
- 여러 섹션의 콘텐츠를 탭으로 구분하여 보여주는 네비게이션 컴포넌트입니다.

### 토스트
- 화면 하단이나 모서리에 잠깐 나타났다 사라지는 알림 메시지 컴포넌트입니다.

### 툴팁
- 요소에 마우스를 올렸을 때 추가 정보를 보여주는 작은 팝업 컴포넌트입니다.

### 팝오버
- 클릭하면 추가 정보나 관련 작업을 보여주는 작은 오버레이 컴포넌트입니다.

### 드롭다운
- 클릭하면 아래에 다양한 리스트를 보여주는 컴포넌트입니다.


## 학습 내용

### Intersection Observer API
- 레이지 로딩과 무한 스크롤 기능을 구현하면서 해당 API에 익숙해졌습니다.
- 페이지가 로딩될 때 모든 이미지를 한 번에 불러오는 대신, 사용자가 스크롤할 때 필요한 이미지만 불러오는 방식으로 최적화하였습니다.
- 결과적으로 페이지 초기 로딩 속도가 개선되었으며, 사용자 경험이 향상되었습니다.

### 합성 컴포넌트 패턴
- 모달과 드롭다운 컴포넌트를 개발하며 합성 컴포넌트 패턴을 학습하였습니다.
- 각 컴포넌트의 관심사를 분리하여 로직과 UI를 개별적으로 관리할 수 있게 되었습니다.
- 이러한 분리는 다양한 상황에 맞춰 컴포넌트를 쉽게 재사용할 수 있는 기반이 되었으며, 유지보수성이 향상되었습니다.

### 헤드리스 UI
- UI와 로직을 분리하여 컴포넌트 재사용성을 높이기 위해 헤드리스 UI 방식을 적용했습니다.
- 로직은 커스텀 훅으로 분리하고, UI는 프로젝트 요구에 맞게 유연하게 변경 가능하도록 구성하였습니다.
- 디자인 요구가 빈번하게 변경될 수 있는 상황에서 UI 변경에 신속하게 대응할 수 있는 구조를 만들어, 향후 개발 과정에서도 유용할 것이라고 생각합니다.

### 포탈
- 포탈을 활용하여 팝오버, 모달 등과 같은 컴포넌트를 DOM 계층을 벗어난 위치에 렌더링하는 방법을 학습했습니다.
- `overflow: hidden`일 때 발생하는 시각적 문제를 효과적으로 해결할 수 있었고, UI 요소의 위치를 독립적으로 관리할 수 있게 되었습니다.
- 이러한 접근 방식은 UI 요소 간의 레이아웃 충돌을 방지하는 데 기여하였습니다.

### Ref를 이용한 외부 클릭 감지
- Ref를 활용하여 컴포넌트 외부에서 발생한 클릭 이벤트를 감지하였습니다.
- 이를 통해 모달이나 드롭다운 컴포넌트를 외부 클릭 시 자동으로 닫을 수 있도록 구현하였습니다.
- 사용자 경험(UX)을 향상시키고, 사용자가 불필요하게 X 버튼을 클릭하여 컴포넌트를 닫는 번거로움을 줄이는 데 기여하였습니다.

### 전역 상태와 지역 상태 관리
- 전역 상태와 지역 상태를 상황에 맞게 적절히 구분하여 사용했습니다.
